# .github
Org-level config for M00C1FER repos — hosts the reusable multi-distro install-test workflow

## Portfolio quick install

Install selected tools from the M00C1FER portfolio with one wizard:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/M00C1FER/.github/main/install-portfolio.sh)
```

This meta-installer lets you choose tools interactively (or via flags like `--all` / `--tools`) and delegates to each tool's own `install.sh`.
